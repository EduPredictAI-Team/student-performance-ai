# MySQL Workbench

[![License](https://img.shields.io/badge/license-GPL--2.0-blue.svg)](License.txt)
[![Official Documentation](https://img.shields.io/badge/docs-MySQL%20Reference-orange.svg)](https://dev.mysql.com/doc/workbench/en/)

[MySQL Workbench](https://mysqlworkbench.org) is the official unified visual tool for database architects, developers, and DBAs. It provides comprehensive data modeling, SQL development, and administrative tools for server configuration, user management, and migration.

MySQL Workbench fully supports **MySQL Server 5.6 and higher**.

## Key Features

* **SQL Development**  
  Build, configure, and manage connections to MySQL servers. Execute queries, optimize performance, and manage scripts with the built-in SQL Editor.

* **Data Modeling & Design**  
  Design visual database schemas, perform forward and reverse engineering between schemas and live databases, and configure tables, columns, indexes, partitions, routines, and views.

* **Server Administration**  
  Manage users, inspect audit logs, view database health, configure backup/recovery, and monitor real-time server performance.

* **Database Migration**  
  Seamlessly migrate schemas and data from Microsoft SQL Server, Microsoft Access, Sybase ASE, SQLite, SQL Anywhere, PostgreSQL, and legacy MySQL versions to modern MySQL instances.

* **MySQL Enterprise Features**  
  Native GUI support for commercial enterprise tooling, including MySQL Enterprise Backup, MySQL Firewall, and MySQL Audit.
